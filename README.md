# ☕ Cuphead HTML

Proyecto inspirado en Cuphead desarrollado con HTML, CSS y JavaScript.

## 🎮 Descripción

Este proyecto busca recrear elementos del videojuego Cuphead utilizando tecnologías web, incluyendo animaciones, mecánicas de juego y diseño inspirado en el estilo clásico de caricaturas de los años 30.

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript

## 📂 Estructura

```text
/
├── index.html
├── css/
├── js/
└── assets/
```

## ▶️ Cómo ejecutar

1. Clona el repositorio.
2. Abre `index.html` en tu navegador.

```bash
git clone https://github.com/tu-usuario/cuphead-html.git
```
